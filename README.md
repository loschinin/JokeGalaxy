# Галактика юмора (JokeGalaxy)

Русскоязычная PWA для поиска и коллекционирования шуток, интерактивной 3D-карты смысловых кластеров и сборки стендап-монологов. Интерфейс адаптирован для мобильных экранов; проект использует React Native for Web, TypeScript, Vite, Go `net/http` и PostgreSQL.

## Что входит

- Бесконечная лента, 3D-карта на Three.js, фильтры по девяти кластерам, сортировка, лайки и избранное.
- Гибридный поиск с отдельными лексическими и смысловыми секциями, режимы «Только по тексту» и «Только по смыслу», голосовой ввод на русском языке.
- Добавление пользовательских шуток с AI-анализом тегов и кластера; коллекция, лента и карта изначально пустые и наполняются только публикациями пользователей.
- Вход через Яндекс ID, публичные профили и серверные SEO-страницы шуток, тегов, кластеров и авторов; `sitemap.xml` и `robots.txt`.
- Студия стендапа: подбор шуток, выбор подачи, потоковая генерация DeepSeek, 50 бесплатных кредитов аккаунту и пакеты оплаты через ЮKassa.
- Панель редакции: CSV-импорт, прогресс фоновой задачи, модерация текста и дублей, история платежей.
- PWA-манифест, офлайн-кэш оболочки и иконки для установки.

## Локальный запуск

Требования: Node.js 20+, npm 10+, Go 1.22+ и PostgreSQL 14+ (для базового предпросмотра без backend достаточно Node.js).

### 1. Frontend

```bash
cd frontend
npm ci
npm run dev
```

Vite слушает `0.0.0.0:5173`, а запросы `/api`, `/auth`, `/sitemap.xml` и `/robots.txt` проксирует на `http://127.0.0.1:8080`. Браузер обращается только к относительным URL. Без backend интерфейс доступен, но не подставляет тестовые аккаунты, шутки или другие записи.

Для production-сборки:

```bash
cd frontend
npm ci
npm run build
```

### 2. PostgreSQL и backend

Создайте базу и пользователя PostgreSQL, затем скопируйте `.env.example` в `.env` и задайте подключение и ключи интеграций. Миграция `backend/migrations/001_init.sql` запускается backend автоматически при старте с доступной базой; она создаёт таблицы, русскую полнотекстовую индексацию, `pg_trgm`, 256-мерные embeddings в `BYTEA` и девять системных кластеров. При запуске также удаляется только аккаунт редакции с точными признаками старого автосида и связанные с ним тестовые шутки; аккаунты Яндекс ID и пользовательские записи не затрагиваются.

После сборки frontend запустите сервер из каталога `backend`:

```bash
cd backend
set -a
. ../.env
set +a
go run ./cmd/server
```

Backend обслуживает API, SSR и production-статические файлы на порту `8080`. Переменная `FRONTEND_DIST` по умолчанию указывает на `../frontend/dist`. Если PostgreSQL не настроен, сервер использует пустое хранилище в памяти; пользовательские записи в нём не переживают перезапуск. Начальные аккаунты и шутки не создаются.

### 3. Яндекс ID и роль редактора

Создайте OAuth-приложение Яндекса с callback URL `{SITE_URL}/auth/yandex/callback`, укажите его `YANDEX_CLIENT_ID` и `YANDEX_CLIENT_SECRET`. Приложение запрашивает профиль, email и аватар. После первого входа назначьте роль редактора конкретному аккаунту через защищённый доступ к базе:

```sql
UPDATE users SET role = 'admin' WHERE yandex_id = '<идентификатор Яндекса>';
```

Идентификатор можно посмотреть в таблице `users`; после изменения роли пользователь должен обновить сессию.

### 4. AI и платежи

- `YANDEX_FOLDER_ID` и `YANDEX_API_KEY` включают настоящие 256-мерные embeddings для semantic search и карты.
- `DEEPSEEK_API_KEY` включает AI-разметку и SSE-генерацию монолога. Без ключа анализ использует эвристики на основе введённого текста, а генерация монолога отключена.
- `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET_KEY` включают реальные платежи. Укажите webhook ЮKassa `{SITE_URL}/api/payments/webhook`; уведомления дополнительно проверяются запросом статуса платежа в API ЮKassa. Email для электронного чека берётся из профиля Яндекса или запрашивается при оформлении; сервер передаёт его в чек ЮKassa по 54-ФЗ.
- Пакеты: 50 генераций за 50 ₽, 100 за 80 ₽, 200 за 140 ₽. В рабочем окружении frontend не начисляет кредиты локально при ошибке оплаты.

### Production

Установите `APP_ENV=production`, HTTPS-адрес `SITE_URL` и случайный `JWT_SECRET` длиной не менее 32 символов. Задайте PostgreSQL, OAuth, AI и платёжные ключи через секреты среды, а не в Git. Для публикации шуток, лайков, избранного, стендап-генерации и редакторских действий требуется сессия; права администратора проверяются на backend для каждого запроса.

## CSV-импорт

Загрузка доступна только администратору. Файл должен быть в UTF-8, разделитель — `;`, размер — до 10 МБ, максимум — 50 000 строк. Поддерживаются колонки в порядке:

```text
id;text;triggers;cluster
```

`triggers` можно разделить запятыми, `|` или `#`; кластер принимается по slug или по названию. Неполные теги дополняются AI-разметкой, координаты и embeddings создаются при импорте, близкие дубликаты помечаются.

## Полезные маршруты

- `/` — галактика и лента.
- `/standup` — генератор монологов.
- `/favorites`, `/user/me`, `/admin` — избранное, профиль и панель редакции.
- `/joke/{id}`, `/cluster/{slug}`, `/tag/{tag}`, `/user/{id}` — SSR-страницы с canonical, Open Graph и schema.org.
- `/api/search?q=...&mode=hybrid|text|semantic` — поиск.
- `/healthz` — состояние HTTP-сервера и PostgreSQL.
